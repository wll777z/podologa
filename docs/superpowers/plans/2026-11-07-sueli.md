# Sueli Local Website Implementation Plan

> **For agentic workers:** Execute natively in this session using the existing checkout. No worktree or remote publication.

**Goal:** A vivid 2.AG-inspired Sueli website with honest browser-local appointment requests and management.
**Architecture:** Static Vite app, separate storage/validation module, DOM interface, self-contained export.
**Tech Stack:** HTML, CSS, ES modules, localStorage, Node, Playwright.
**Spec:** ../specs/2026-11-07-sueli-design.md

## Global Constraints
Use the supplied palette and Inter Tight. No fake professional facts. Requests are local and not sent. No push. Keep the Seed archive intact.

## Review Focus
